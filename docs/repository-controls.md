# Repository controls

`p2ppsr/interop` remains private. P2PPSR authorizes public release separately under [GOVERNANCE.md](../GOVERNANCE.md).

The `offline-core` GitHub Actions job runs on pushes and pull requests with read-only repository permissions, no persisted checkout credentials, pinned action commits and the Node version in `.nvmrc`. It checks core behavior, catalogs, qualification execution, retained journals, packaging and journal preservation. Journal integrity checks compare retained bytes and content digests; new results and corrections are appended.

Server-enforced branch protection is unavailable under the current private-repository account plan. Signed checkpoints and independent mirrors are not established. Reports identify these limits. A future certification program defines additional publication and independent-review requirements before certification is offered.

The authorized prelaunch Git history replacement establishes a new source baseline while retaining evaluation evidence unchanged. Recorded historical revisions remain execution provenance; they are not rewritten to identify the new baseline. Subsequent changes preserve the retained evidence under the journal history guard.
